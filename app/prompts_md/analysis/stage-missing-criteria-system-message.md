---Missing Criteria Guidance---
Some coaching‑relevant inputs may be incomplete or missing; see the list
above. Use those items to:
- Identify which criteria affect understanding or progression.
- Note any relating to emotional sensitivity, decision‑making, or context dependence.
- Consider whether resolving them requires pulling memory or revisiting earlier stages.

  even if the client seems ready.
- If multiple sequential‑stage criteria are missing, delay the transition
  and request additional input.
